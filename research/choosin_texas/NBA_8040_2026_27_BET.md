## Why this book, not a richer cut

NCAAB did not make 2Q-vs-3Q a law. It did not make 56–60¢, lead 4–6,
or 41–45¢ a law. Skip-4–6 helped full samples and hurt IN / tiny OOS
on both sports.

The only same-sign usable-n cell in both sports is **lead 4–6 × open
≥71¢**. On the registered baseline that cell is 6/12, −10.0000¢,
book −120¢, 2 W∩T40. It is a **watch**, not a skip lock. Applying it
as a filter would be fitting 2025-26 again.

So the convertible object is the small book that actually survived
replication: NBA 2Q, regular season, 80/40, 1 contract, no invented
exit.

## Later conversion (paper → Risk → live)

This file does not arm live trading.

A later program, if one is opened, must:

1. Keep this `book_id` frozen. Do not silently change the rule.
2. Paper the same book. Reconstruct. Do not invent fills.
3. Pass every order through the Risk Decision Engine. Strategy code
   must not submit to Kalshi.
4. Require explicit `mode=live`, `live.enabled=true`, and
   `live.confirmation=ENABLE_LIVE_TRADING`. Presence of keys is not
   enough.
5. Treat UNKNOWN after a timeout as reconcile, not retry.
6. Stop new exposure when state is inconsistent.

Until that program exists, the only authorized object is this
research-registered book on Choosin Texas.
