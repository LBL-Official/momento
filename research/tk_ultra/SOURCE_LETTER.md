Relative Value

Wing price: example Nasdaq futures 14033
Base price: example ES futures(S&P 500) 4382.50
Beta(Nasdaq volatility compared to ES volatility) : 1.325 (determined by Nq vol 28.5 / ES vol 21.5)
Wing anchor price: example the Nasdaq closing price 13954.8
Base anchor price: example the ES(SPX) closing price 4349.46

OK what to do with all these numbers?

(Wing price/ base price) * beta = (14033/4382.50) *1.325 = 4.2427

(Base price(4382.50) - base anchor price(4349.46)) * 4.2427 = 140.1788

Wing price(14033) - (140.1788 + wing anchor price(13954.8) = -61.979


Ticks per handle of wing(for nasdaq, 4 ticks comprise one dollar/handle since it trades in quarter ticks)


-61.979 * ticks per Nasdaq handle(4) : -247.92

This is how many ticks cheap the Nasdaq is to the S&Ps today. This formula you can use for anything and everything to express the performance of a relationship between one product and another, in a very simple format that compiles everything into one number. This equation is the foundation of relative value for us.

Learn this formula and try applying to other products you want to compare.
